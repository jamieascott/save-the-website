# 🔐 Save the Website

## TY Engineering Escape Room

A browser-based engineering escape room designed for Transition Year students.

### Mission

You're the engineering team.

The new school website launches in 45 minutes.

Find the bugs, decode the system, fix the problems and get the website live.

## Features

- 10 sequential locks
- 45-minute countdown
- Driver / Navigator roles
- Binary and encryption
- Debugging
- Data and JSON
- UX challenges
- AI / prompt engineering
- Brand recognition
- Workhuman recognition and rewards
- Incident response
- Mobile-friendly
- No login
- No student data collection
- Local progress saving

## Running the Game

Open `index.html` in a modern browser.

No server is required.
